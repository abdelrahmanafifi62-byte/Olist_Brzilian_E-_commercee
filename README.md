# Olist Brazilian E-Commerce Analysis

## 📊 Project Overview

This project analyzes the **Brazilian E-Commerce Public Dataset by Olist** to understand sales performance, customer behavior, product performance, payment patterns, and delivery operations.

The project covers the complete data analysis workflow, starting from raw data cleaning and transformation using Python and ending with an interactive Power BI dashboard for business insights.

---

## 🎯 Project Objectives

The main objectives of this project are to:

* Analyze overall e-commerce sales performance.
* Understand customer purchasing behavior.
* Identify top-performing products and sellers.
* Analyze payment methods and order values.
* Evaluate order delivery and shipping performance.
* Measure delivery delays and on-time delivery performance.
* Identify trends and patterns that can support business decisions.

## 🔄 Data Analysis Workflow

### 1. Data Cleaning

The raw Olist datasets were cleaned and prepared using Python.

The cleaning process included:

* Checking for missing values.
* Detecting and handling duplicates.
* Standardizing text values.
* Cleaning geographical data.
* Handling inconsistent city names.
* Preparing datasets for analysis.
* Creating calculated fields required for the analysis.

---

### 2. Exploratory Data Analysis

The cleaned datasets were analyzed to identify:

* Sales trends.
* Order volume.
* Customer behavior.
* Product performance.
* Seller performance.
* Payment behavior.
* Review patterns.
* Shipping and delivery performance.

---

### 3. Data Modeling

The cleaned datasets were structured and connected to create an analytical data model suitable for Power BI.

The model connects major business entities such as:

* Customers
* Orders
* Order Items
* Products
* Sellers
* Payments
* Reviews
* Geolocation
